## 不可省略的原则

1. **读者体验可恢复。** 原位显示不能毁坏原始内容；一键恢复，失败保留原图；页面正常阅读不被后台任务长期阻塞。
2. **真实链路。** 真实输入经过实际 OCR、翻译、文字清除和排版。模拟服务只用于隔离测试，必须标记，不能作为产品成功证据。
3. **质量可度量。** 检测召回、擦字残留、译文可读性、任务成功率、耗时和单位成本分别测量，不能用一张好看样图代替。
4. **权限和数据最小化。** 扫描默认本地；提交选中图片前清楚告知上传范围。页面无需获得服务商密钥。用户内容不得进入公共仓库或默认训练集。
5. **计费可追溯。** 价格和预计额度在执行前可见，重试及重复消息不重复扣费；账本与任务状态可以对账。
6. **授权分层核实。** 代码、基础模型、微调权重、数据集、字体和样本的权利分别记录。研究可用不等于商用可发布。
7. **失败有出口。** 不确定广告不默认选择；复杂艺术字可以降级为译注；无法访问的图给原因和手动入口。
8. **Windows / UTF-8。** 项目开发、文档命令与启动脚本优先适配 Windows PowerShell；文本 UTF-8。未来服务端可用 Linux 容器，但不得假定用户机器是 Linux。
9. **规格驱动变更。** 先更新需求/决策和受影响任务，再实现；不因难做悄悄删除验收。
10. **证据驱动交接。** 实际执行与计划明确分开。上一阶段缺少总结或证据时不能宣称已具备下一阶段前提。

## 通用完成定义

- 本阶段需求对应的任务和验收均有记录。
- 实际产物可定位、可运行或可检查；运行依赖、版本和限制已说明。
- 按变更风险执行必要验证；故障已处理或登记为不阻塞的后续任务。
- 无关键密钥、个人浏览数据、未经许可素材进入提交。
- 报告包含上一阶段完整总结、本阶段完整总结、明确下一步结论。
- Git 交付状态可核对，不把未推送的本地提交算作远端交付。

## 自动推进与人工信息边界

用户已授权逐步落实和推送现有远端；日常实现、验证、文档和推送无需每步重复询问。需要业务事实、服务商账户或新的付费支出时说明具体缺失信息；继续独立任务。需求中的暂定方案不冒充用户已确定的价格、品牌或法律结论。

本轮完成规格基线，实施轮次按阶段推进，不自动把本轮扩展成购买服务、生产部署或商店上架。
