## 标注复核：官方源与原图对应

在官方站点找到三页韩文 SVG 语言源，而非使用某个 OCR 的输出作为答案。逐项核对源元素与冻结高清裁图，修正货币名、角色名各一处，并补齐之前无法确认的拉长喊声。第 1 话 SVG 同时含旧文本和现用文本，按实际图片匹配使用现用元素，未简单拼接所有文本。

8 处均有源文本对应；新参考共 144 个规范化字符，其中原七处仍为 126 字符。参考 SHA256 为 `32705a626fabfe3cc95bf3dbee172b9d12f9a9139ca0831e32f7194fe49b8b0e`。官方源 URL、逐文件哈希、精确元素 ID、裁图位置及变更标记见 [可复核索引](../datasets/korean-reference-v2.json)。完整旧值、新值和 SVG 留在本机私有目录；重建脚本已验证与冻结 v2 字节哈希相同。

这是**官方源辅助参考，由 AI 对照原图复核**，不是人工签字或独立双人审核。八处均来自同一作品三个章节的开发样本；框仍是带留白的参考裁图，不能据此报告整页检测召回。韩国原创样本依然为 0。

## 新模型及实际运行方式

实测新增一种识别权重：[PaddlePaddle 官方 Korean PP-OCRv5 mobile ONNX](https://huggingface.co/PaddlePaddle/korean_PP-OCRv5_mobile_rec_onnx)。与现有 Tesseract fast 比较，不把配置数量说成模型数量。版本固定为 `5c6f574b8e2230adf4287b33e736d71b9fabd28e`，模型卡标 Apache-2.0；训练素材权利未独立审计，不等于整产品商用许可全部完成。

ONNX 文件 13,418,787 字节，SHA256 `92f0b7785e64fc9090106a241cf4c1eb97472824558272751b88a2a4476d3a08`，与发布方 LFS 元数据一致。首次下载遇截断、ONNX 拒绝加载；随后断点补齐并验证大小/哈希，截断文件未用于成绩。字典及配置同步固定，登记于 [模型清单](../models/korean-ocr-candidates.json)。推理前验证每个文件哈希。

使用现有 ONNX Runtime CPU、4 个计算线程；增加 PyYAML 6.0.3 读取官方字典配置，依赖已锁定。输入按官方配置的 BGR、48 像素高、归一化及 CTC 字典解码适配，动态宽度上限 3200。参考：[官方识别预处理](https://github.com/PaddlePaddle/PaddleOCR/blob/main/tools/infer/predict_rec.py)。

模型针对单行文字，所以同时保留“整框误用对照”和“自动分行”结果。分行只根据图像暗笔画与水平投影，不读取答案、人工行数或 SVG 坐标；参考框本身仍由上一轮选定。为区分分行与模型的贡献，另让 Tesseract 使用完全相同的自动分行裁图。

## 同一新版参考下的结果

主口径保留空格和标点；NFKC 及连续空白归一。全部 8 处参考裁图均运行，旧四配置输出重新按 v2 计分，不能直接沿用旧报告百分比。

| 候选配置 | 错误 / 144 字符 | CER |
|---|---:|---:|
| **Paddle v5 + 自动分行** | **17/144** | **11.81%** |
| Tesseract 原尺寸整块 | 47/144 | 32.64% |
| Tesseract 3 倍整块（旧诊断默认） | 51/144 | 35.42% |
| Tesseract 3 倍二值化整块 | 50/144 | 34.72% |
| Tesseract + 相同自动分行 | 58/144 | 40.28% |
| Tesseract 3 倍稀疏模式 | 113/144 | 78.47% |
| Paddle v5 直接输入多行整框（错误使用方式对照） | 140/144 | 97.22% |

原七处的同样本对照：Paddle 分行 17/126，Tesseract 原尺寸 46/126、旧诊断默认 49/126。修正答案后旧模型分数也变化，这是参考修订带来的变化，不能当作模型改进。完整逐区域、去空格口径、代码与复用输出哈希见 [脱敏实测证据](evidence/P01-korean-models.json)。

Paddle 分行有 4/8 处文本与新参考完全一致；剩余主要是省略号漏识别、词间空格，以及一处多识别韩文字。去空格后仍有 13/117 错误（11.11%），所以不能靠删除空格宣称近乎全对。自动分行可能丢弃小标点或拆出空行，后续应单独验证。

新模型已经表现出值得继续验证的改善，但**尚未替换生产默认 OCR**。这里只比较参考裁图，不包括整页漏检、气泡修复或翻译；不得把 11.81% CER 解读成成品成功率。两个实跑 run（models-v1、models-v2）字符结果一致，第二次用于核验最终适配器与展示；旧证据未覆盖。

推理在本机完成，原图未上传识别服务，新增翻译请求为 0。耗时记录包含单次小样本且不同方案的初始化计时范围不同，不能给性能排名、P95 或 SLA。正式插件与 4176 实验阅读器默认模型未改变；此次也没有重新修改气泡覆盖算法或声称覆盖数提高。
