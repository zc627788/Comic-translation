1. 增加显式 korean_ocr 选项，默认 tesseract，候选 paddle-v5。候选沿用自动检测的原彩色裁图与自动分行，不使用参考答案；日文路线不变。
2. 擦字安全门槛保持原样。候选识别为空、任一候选行为空或最低行置信低于暂定 0.65 时保留原文；该阈值是实验拒绝策略，不能与 Tesseract 置信度等价解释。
3. 固定 30 图以新 run ID 实跑诊断和流水线。诊断不被擦字拒绝跳过；默认只读真实翻译缓存，不把缓存未命中当模型失败或翻译完成。
4. 逐图对比 guard-v2 的检测、识别、失败和像素结果，合成真值指标单列；真实 24 页未完整标注，不报告整体准确率。保存参数、代码哈希和来源，公开仅脱敏结果。
