# 日文 / 韩文气泡覆盖实验：运行与复查

阶段：P01 局部验证；上游：[免费接口实验完整总结](../reports/P01-free-api-probe.md)。

## 本轮目标

按 DEC-015 将韩语纳入输入语言，并把自动气泡检测、真实 OCR、免费翻译、擦字、嵌字串联到自有阅读器。覆盖成功与语言质量分别记录。正式扩展仍使用原基础接口，不能将本阅读器当成扩展商店版本。

## Windows 启动

在仓库根目录使用 PowerShell；全部文本 UTF-8：

```powershell
.\scripts\setup.ps1
.venv\Scripts\python.exe -m scripts.fetch-bubble-models
.venv\Scripts\python.exe -m scripts.prepare-bubble-samples --allow-download
.\scripts\start-bubble-lab.ps1
```

打开 `http://127.0.0.1:4176/`。选择测试页，点击“检测气泡并覆盖中文”，或 Ctrl+Shift+左键点击图像。实际任务状态驱动扫描动画；没有虚构百分比。处理后图片直接变为译图，支持恢复原图、显示译图、查看检测框、导出 PNG 和逐气泡核对。

依赖由 `uv.lock` / `package-lock.json` 固定；默认安装 dev 与 vision 两个组，约 156 MiB 模型另行显式下载。模型校验成功后才加载，请求期间不下载模型、不运行远程 Python、不自动购买服务。下载被截断时脚本会失败，重新执行后仍校验 SHA256。

韩文长条图由本项目原创生成。韩文彩漫来自 Pepper&Carrot 官方 CC BY 页，脚本下载高清原作并等比缩至 2400 像素宽。日文样本沿用上一实验的私有 `page-007.png`，准备方式见 [免费实验说明](free-api-experiment.md)；没有该文件时页面明确显示未准备，不伪造样本。字体使用本机 Windows 微软雅黑 / Malgun Gothic，字体文件不随仓库分发。

## 处理方式与边界

- RT-DETR-v2 同时检测气泡、气泡内文字与气泡外文字。长图切片重叠、还原全图坐标、去重。本轮只覆盖已匹配的气泡对白，拟声词和艺术字保留。
- `ja` 使用本地 manga-ocr ONNX int8；`ko` 使用本地 Tesseract.js 韩文模型，保留词间空格。白底直接识别裁图，彩色气泡先隔离暗色笔画再识别；无人工框选、补字或预置中文译文。
- 纯白气泡提取内部安全区；开放边界只有满足气泡内距、白色角点等保守条件时，限于文字矩形处理，否则保留。浅色半透明气泡使用文字笔画掩膜和 OpenCV Telea 修复，未接入 LaMa。深色/复杂气泡暂不支持。
- 中文自动断行、随原图尺寸调整字号；装不下或越界时先失败再保留原图。逐气泡和整图都检查安全区外像素未改变。此检查不能证明安全区内没有误擦或 OCR 正确。
- MyMemory 仅接收 OCR 文本；无密钥、无自动重试、无付费兜底。持久化语言隔离缓存及 1,000 字符本地实验上限；缓存命中明确显示，首次网络耗时不能算本次网络耗时。
- 服务只监听本机 4176，固定样本/文件白名单、限制来源与主机、单任务串行、每服务进程最多 20 个任务，不接受任意路径或 URL。是受限实验服务，不提供账户、多租户、任意上传或生产鉴权。
- 恢复原图不会取消已经发送的翻译请求，但会阻止当前任务完成后自动切回译图；换页也不会把旧任务结果贴到新图。

不要同时用命令行和阅读器运行多份处理服务；实验缓存仅设计为单进程单任务。更换模型 / OCR 版本后重新生成任务；译文缓存按服务版本、源语言、目标语言及实际 OCR 文本隔离。
