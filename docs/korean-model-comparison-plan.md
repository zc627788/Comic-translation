## 本轮范围

1. 先复核标注：优先将官方语言源 SVG 文本与冻结原图逐行对应，保留源 URL、SHA256、旧值/新值及原因。此为官方源文本交叉核对，不冒充人工或独立双人审核。源图不一致或不清楚的项仍排除主指标。旧标注不覆盖。
2. 采用 PaddlePaddle 官方发布的 Korean PP-OCRv5 mobile ONNX 与旧 Tesseract fast 实测比较；官方模型卡标 Apache-2.0，下载前登记版本/许可，下载后登记哈希。只在本机用现有 ONNX Runtime，权重不入 Git。
3. PP-OCRv5 为文本行识别器，不能把整段多行压成一行成绩当正常使用。分别运行整框直接识别和不使用答案的自动行切分，明确候选是完整识别配置；参考裁图与自动整页检测验收分开。旧四配置输出用同一新标注重新计分，不能直接比较不同真值的百分比。
4. 保留每区域全部输出/耗时、分词空格和标点错误；未评分区也运行并保留。只有开发集改善不自动替换生产默认，更不意味着气泡覆盖或翻译质量完成。
5. 做适配器边界测试、完整工程检查、本地可视对照和脱敏报告，再提交推送。无付费 API、不上传原图到识别服务。
