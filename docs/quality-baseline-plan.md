## 本轮范围与交付

先冻结可复现的约 30 张工程回归输入，登记来源、许可、文件哈希、原作分组、处理分辨率、主类别、附加标签和是否合成。优先实际取得有权使用的日漫与韩文漫画；找不到可核实的韩国原创韩漫时明确记录缺口，不用外国作品韩文版冒充。未经确认允许改编的公开图片不纳入擦字/翻译集。

初始可用组成：12 页官方日漫 + 12 页 Pepper&Carrot 韩文版 + 6 张原创受控夹具。这 30 张是开发回归集，不是完整代表性质量集、30 张商业韩漫或 240 张留出验收集。相同作品、裁切、压缩及重排版本须保持同一 family，不得分散到训练/验证来制造独立性。

受控夹具必须覆盖韩文长图切片接缝、韩文小字/低清、深色气泡、日文注音/竖排、不规则对白和空白负样本。生成器自有原文仅作为独立评估真值，绝不可直接送入翻译流程或顶替 OCR。真实页的属性由预览确认，尚未人工标注的正文数、CER、误擦率、译义分数保持 null，不能填 0。

## 本轮步骤与验收

1. B01 来源筛选：保留采集 URL、许可 URL、署名、允许用途、拒绝/待确认来源。每页可追溯至原作位置。
2. B02 固定输入：30 个唯一输入 ID 与 SHA256，保存只读冻结清单。生成后目视查看联系表，空白、封面、无对白页也保留标签，不能因结果差而替换。
3. B03 标注契约：独立原文、xyxy 图像坐标、可辨认标记、正文/注音/艺术字、阅读顺序、保护区；人工修订必须新版本。原创夹具可由生成器提供精确真值，但只单列其指标。
4. B04 自动基线：所有输入运行实际检测与 OCR，保留掩膜拒绝、未检测、识别失败；OCR 诊断不被擦字安全门槛阻止。整链路默认只读旧真实翻译缓存，未命中明确记为未执行翻译，不预置译文，不重置已有预算。显式允许网络时仍使用已有持久化 1,000 字符总上限。
5. B05 证据交接：产出私有逐图结果/核对页面、公开脱敏清单/统计、失败分类与下一轮任务，检查后提交推送。只放行基于固定输入的 OCR 比较，不以缓存缺口放行完整 T010。

## 指标口径

- 输入数与来源代表性分开：真实日漫 / 韩文译版 / 韩国原创 / 合成图分别统计。
- 检测召回分母来自独立标注。匹配采用正文框覆盖率 >=90%，一对一匹配，不以检测器输出作为真值。
- OCR 分为已匹配框的条件 CER，以及缺失框计为整段删除的端到端 CER。NFKC、统一空白、保留韩文词间单空格；同时报告去空格指标，不能选择较好结果替代主指标。
- 输出原文与真值通过独立 ID 匹配；漏检、拒绝、未知标注与空白负样本单列。空白页不虚构 0/0 CER。
- 覆盖数只说明像素链路执行；擦字残留/背景损坏与译义需人工审阅，未审阅不得报通过率。日中/韩中译义需对应语言评审；单个助手观察不是双人盲评。
- 各阶段耗时、真实网络/缓存命中、拒绝原因分开。30 页一次串行不是 P95 或并发 SLA 验收。
