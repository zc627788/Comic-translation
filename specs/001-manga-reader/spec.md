# 产品需求规格

文档编号：D02；版本：0.1；日期：2026-09-28；上游：[D01 项目原则](../../.specify/memory/constitution.md)。

## 上一份完整总结

D01 建立可恢复阅读、真实模型链路、可度量质量、最小权限、可追溯计费、分层授权、失败出口、Windows/UTF-8、规格先于变更和证据交接共 10 条原则。日常开发与向已配置远端推送已在授权范围内；未知付费、生产部署和商店上架不由文档自动触发。上游放行需求编写，尚无技术或商业实测。

## 目标与用户

让桌面用户在有权访问和处理的日漫图片上，少操作地获得可读的中文译文，保留原图和修正机会。核心价值是读完一章时不被下载、上传、等待及失败打断。

首要用户：使用 Windows Chrome/Edge 阅读日文漫画、希望原页显示中文的个人读者。次要探索对象为获得内容授权的独立创作者；专业出版社生产流程不属于 v1。

“完整开发”包括插件、处理服务、真实模型适配、账户额度、可测试的支付集成、质量和部署文档。实际启用商业收款与公开发布另需满足发布门槛。

## 范围基线

| 分类 | v1 范围 |
|---|---|
| 平台 | Windows 10/11 的桌面 Chrome、Edge；发布时当前稳定版及前一主版本 |
| 语言 | 日语输入、简体中文输出；数据结构预留其他语言 |
| 页面 | 普通 HTML 图片阅读器，包含懒加载、响应式图和长图；少量有权测试的重点站点 |
| 入口 | 单图悬浮/右键、Ctrl+Shift+左键、侧栏扫描批量选择 |
| 结果 | 原位译图、原图对照、单图/有序 ZIP 导出、基础纠错 |
| 模式 | 快速阅读、精细处理；复杂区域可降级为译注并明确标示 |
| 服务 | 云端处理为首版基线；本地推理作为后续优化，不作为必达首发项 |

v1 不承诺：所有网站、未加载图片或付费墙后的内容；移动浏览器；动画每帧翻译；PDF 阅读器、特殊 Canvas 拼图的完整适配；漫画分发平台；出版级无痕重绘；所有艺术拟声词自动重绘；离线全流程；无限额度。

“智能识别”表示推荐勾选漫画正文、排除疑似广告，不表示分类永远正确。“仅 OCR 导出”暂列后续需求，不能把用户原话中的可能笔误直接扩成另一个主产品。

## 用户故事及优先级

优先级 A：单图核心闭环；B：可日常使用的完整阅读；C：商业版本。C 不得因排在后面就在商业发布时省略。

| 故事 | 优先级 | 用户目标 | 验收示例 |
|---|---|---|---|
| US-01 | A | 点一张图原位看中文 | 给定支持的图片和有效服务配置，提交后显示真实处理结果，能恢复原图 |
| US-02 | B | 扫描后选择整章 | 展示当前已发现图片、推荐选择及疑似广告；仅上传提交时所选图片 |
| US-03 | B | 用快捷操作少点按钮 | 已授权站点中按组合键点击，定位到正确图片并显示状态，不误翻译旁边图片 |
| US-04 | B | 保存处理结果 | 按页面阅读顺序导出成功结果，说明失败项，文件可正常打开 |
| US-05 | B | 修正少量错误 | 改译文、位置或字号后更新同一结果，撤销后可回到前版 |
| US-06 | B | 连续阅读不丢任务 | 滚动、窗口缩放、懒加载替换后不会覆盖错图；重开侧栏能恢复任务状态 |
| US-07 | C | 清楚知道花费 | 提交前看到额度估算与上限；重复点击不重复扣费，失败释放预留额度 |
| US-08 | C | 安全管理账户与内容 | 自己只能访问自己的任务；能删除结果、撤销站点授权、退出账户 |

## 功能需求

### 图片发现与提交

- **FR-001（A）站点授权。** 用户主动启动后申请当前站点所需权限；跨域图片域按需申请。拒绝权限时提供说明，页面仍可正常使用。不能默认扫描所有历史标签页。
- **FR-002（B）图片发现。** 找到当前文档中的普通 `img/picture`，使用实际展示源与自然分辨率；识别懒加载变化，记录尚未加载和无法读取的项目；重复扫描不生成重复项。
- **FR-003（B）缩略图选择。** 侧栏展示缩略图、顺序、尺寸、状态和勾选；支持推荐、全选可用项、全部取消和手动选择。任何排除项均可查看，不偷偷隐藏正文。
- **FR-004（B）智能推荐。** 综合位置、尺寸、同组特征、广告标记和轻量内容判断；高置信度漫画默认选中，疑似广告/未知不选；说明简短原因。推荐阶段不为未选择的图片上传云端内容。
- **FR-005（B）加载与读取降级。** 滚动后增量发现，不默认自动滚完整站点；原图读取失败可手动重试或用户主动框选可见区域，截图需清楚说明范围与分辨率，不上传整屏无关内容。
- **FR-006（A）提交快照。** 冻结用户选择、语言、模式和图片身份，执行前显示张数/标准页数、预计额度及最大预留额。运行中新增图片不能自动加入本次已确认批次。

### 识别与翻译流水线

- **FR-007（A）区域分离。** 独立保存文字检测范围、气泡区域、实际擦字掩膜与排版安全区；三者不能互相冒充。原始坐标与处理缩放可追溯。
- **FR-008（A）OCR。** 支持日文横排、竖排和带振假名区域；保存原文及质量标记。无文本不虚构对白，低置信或异常结果标为需检查。
- **FR-009（A）阅读顺序与上下文翻译。** 以区域 ID 关联译文，按页组织上下文，避免单气泡孤立翻译；后续加入作品术语表与已读摘要。缺失/重复 ID、空译文、不可解析返回需重试或明确失败。
- **FR-010（A）分级擦字与修复。** 纯色气泡在安全区内清除文字；复杂背景仅修复文字掩膜。低把握时保留原画加译注，不以白色矩形大面积毁图。
- **FR-011（A）嵌字。** 在安全区内断行和设置字号、行距、颜色、描边；有最小可读字号，装不下时提示或改译文，禁止越界遮挡邻近区域。明确横排为首版默认。
- **FR-012（B）长图。** 超长图片分块并保留重叠，合并重复区域，保持全图坐标及上下文；导出合并结果或超尺寸时有序分段，不能漏掉分界文字。
- **FR-013（B）拟声词与复杂文字。** 对对白、旁白、艺术拟声词作策略区分；艺术字默认保留原文并可显示译注。不得宣传所有画面文字均无痕替换。
- **FR-014（B）质量回退。** 用户可报告漏字或框选补译；自动检查残留/溢出等异常；视觉模型补救只针对需要区域，在既定额度上限内执行，否则先报新估价。

### 页面阅读与操作

- **FR-015（A）原位覆盖。** 译图/覆盖层准确对应原图，适应滚动、缩放、尺寸变化和图片源替换；不能破坏网站布局和正常链接操作。旧图片任务不能覆盖新图片。
- **FR-016（A）原图对照。** 单图切换原图/译图、整页恢复；恢复不取消可复用结果。卸载/禁用扩展后站点仍可用，刷新不会永久改写源网站。
- **FR-017（B）快捷触发。** 默认 Ctrl+Shift+左键；可关闭或自定义，输入框不拦截；有右键/悬浮替代入口。未取得站点权限时明确引导先启用插件。
- **FR-018（A）真实状态。** 显示排队、识别、翻译、修复、排版、完成/失败等真实状态；未知进度用阶段动画，不伪造百分比。支持减少动态效果、键盘访问和状态文本。
- **FR-019（B）批量任务。** 顺序与并发分离，当前阅读图优先；支持取消排队、单项重试、部分成功继续、重启恢复；取消反馈与服务端实际取消状态一致。
- **FR-020（B）编辑与撤销。** 可编辑译文、字号、位置，框选补充区域；保留版本和恢复入口。只改排版无需重新付 OCR/翻译费用；补译新增内容可单独估价。

### 导出与结果复用

- **FR-021（B）图片导出。** 单张 PNG/JPEG 与有序 ZIP；输出尺寸与策略可见，文件命名稳定。批次中失败项在清单注明，不用原图冒充译图。
- **FR-022（B）结果复用。** 相同用户、图片内容、语言、模式、术语和模型版本下复用成功结果；编辑生成新版本。默认不跨用户共享原图、译文或缓存。
- **FR-023（B）受控历史。** 展示任务摘要和有效期，失效资源给出重建提示；默认不长期存储浏览地址。用户可删结果，系统执行约定清理策略。

### 账户、商业化与控制

- **FR-024（C）身份与隔离。** 试用会话与注册账户的额度/任务清楚归属；登录、退出、会话到期、换账户都正确处理，任何资源访问都校验所属用户。
- **FR-025（C）试用和套餐。** 有限试用、订阅含额度和加量包；套餐表、有效期、续费说明可见。具体价格待成本与需求实验决定，不硬编码虚构正式价格。
- **FR-026（C）额度账本。** 执行前预留、成功结算、失败/取消释放；部分成功按项结算。金额以整数最小单位、额度以整数 credit 存储；余额不能因并发透支。
- **FR-027（C）支付生命周期。** 支付以服务端核验为准，处理重复回调、乱序事件、退款、拒付、续订失败和取消续订。沙箱可完整演练，真实交易只在发布门槛满足后启用。
- **FR-028（C）用量和争议。** 用户能查看额度变动关联的任务与支付；支持针对失败任务复核并记录人工调整原因，不能直接随意改余额。
- **FR-029（C）运营与限流。** 具备脱敏错误监控、单用户/全局队列和成本上限、模型熔断、健康状态与审计；管理入口需要角色校验，默认不查看用户漫画。

### 安全、授权与交付

- **FR-030（A）上传告知。** 扫描前后均不默认上传未选图；提交说明接收方类型、用途、保存时间和第三方翻译处理。更改处理方时更新披露。
- **FR-031（C）删除与保留。** 原图、结果、文本、缓存与日志的期限分开；请求删除可跟踪。备份清除期限及账务必要保留单独披露，不承诺无法兑现的即时全盘删除。
- **FR-032（A）输入与密钥安全。** API 密钥只在可信服务端；上传校验实际文件内容、尺寸和资源预算；防任意地址读取、跨用户访问、页面注入和恶意模型输出。
- **FR-033（C）第三方清单。** 固定模型/代码/字体版本、来源、哈希和许可记录；未明确商用权利不得作为商业版本默认组件分发或使用。
- **FR-034（C）可构建交付。** Windows 开发启动说明、锁定依赖、扩展安装包、服务端部署说明、配置样例、备份恢复及回滚步骤齐全；全新环境可复现。
- **FR-035（C）Git 与发布。** 不含密钥/私图/权重；正常提交推送并验证远端哈希；版本说明区分已验证站点、已知限制和未启用能力。
- **FR-036（全程）阶段闭环。** 每阶段引用完整上游总结，交付总结和证据，明确是否可以下一步。需求变更同步任务、验收与进度。

## 非功能需求

| 编号 | 要求 | 初始验收方向 |
|---|---|---|
| NFR-001 | 响应与速度 | 点击后 300ms 内有本地反馈；性能基线和服务端延迟见验收文档 |
| NFR-002 | 图片质量 | 不以过度缩图换速度；记录 OCR 分辨率、掩膜质量和排版溢出 |
| NFR-003 | 可恢复性 | 可重连任务、去重提交、恢复原图，服务重启不造成重复扣费 |
| NFR-004 | 资源边界 | 单图、长图、批次、并发、超时及重试均有明确限制 |
| NFR-005 | 隐私与安全 | 最小权限、HTTPS、租户隔离、资源到期和结构化脱敏日志 |
| NFR-006 | 易用与可访问性 | 清楚中文文案、键盘可达、非纯颜色状态、减少动态效果 |
| NFR-007 | 可观测与成本 | 记录各阶段耗时、版本、错误类别与估算成本，不默认记录正文 |
| NFR-008 | 可替换性 | 模型、翻译服务和支付服务有边界，变化不要求重写用户流程 |
| NFR-009 | 可维护 | 有版本化契约、锁定依赖、变更记录及与风险相称的测试 |
| NFR-010 | 国际化预留 | 数据中显式存语言与阅读方向，首版不承诺额外语种质量 |

所有数值指标在验收文档中定义为待验证目标，不属于已达到的宣传数据。
