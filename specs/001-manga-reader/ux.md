# 用户体验与交互规格

文档编号：D07；版本：0.1；上游：[D06 接口契约](contracts.md)。

## 上一份完整总结

D06 定义本地估算和上传告知先于上传，服务端校验后报价不得超过用户确认上限；任务、编辑和导出使用明确版本。任务状态有序号和重连通路，失败、权限、超限和价格变更有操作出口。API、身份/支付提供方尚未实现。上游放行界面细节，不把接口草案当作运行服务。

## 页面清单

| 界面 | 主要内容 | 必须状态 |
|---|---|---|
| 插件入口 | 启用当前站点、打开侧栏、设置入口 | 未授权/已启用/受限页面 |
| 扫描侧栏 | 图片网格、选择工具、目标语言、模式、估价、提交 | 空白/扫描中/部分加载/可提交/无可用图 |
| 图片浮层 | 翻译入口、阶段、原译切换、编辑、导出 | 未处理/排队/处理中/成功/警告/失败 |
| 批次列表 | 固定顺序、各项状态、取消/重试、批量导出 | 部分成功/全部完成/离线/恢复中 |
| 轻量编辑器 | 原图对照、区域选择、原文和译文、字号/位置、撤销 | 未修改/保存中/冲突/已过期 |
| 设置 | 快捷键、模式、字体偏好、减少动画、缓存、站点授权 | 冲突/权限撤销/缓存清理 |
| 账户与用量 | 登录、套餐、余额、历史流水、续订管理、删除 | 试用/有效/过期/付款处理中/会话过期 |
| 运营入口 | 脱敏任务错误、成本和限流、账本复核 | 仅授权运营角色可见 |

本轮提供行为规格，不预先确定品牌视觉或承诺设计稿已完成。UI 文案面向读者，模型名、队列内部错误和数据库字段不直接展示为主流程术语。

## 入口一：批量扫描

1. 用户点击插件并启用当前站点；需要额外图片域权限时解释用途。
2. 侧栏显示“扫描当前已加载图片”，本地枚举候选；滚动后列表增量更新。
3. 默认选高置信度漫画，疑似广告/未知保持不选。缩略图显示序号、宽高、推荐原因和不可读取说明。
4. 状态栏显示“已发现 N 张，已选 M 张，部分图片尚未加载”；不能写“整章全部找齐”除非确有可靠站点页数证明。
5. 用户可只看推荐、查看未选、全选可用项和全部取消；原选择在重新扫描时保留，新增图不会自动进入运行中的批次。
6. 提交前展示语言、处理模式、预计标准页、额度上限、上传/保留说明。无余额、无权限、无图片分别提示原因。
7. 执行后按阅读顺序显示结果，当前视口图优先处理；翻页仍可在侧栏查看已提交批次。

### 推荐标签

“漫画正文（推荐）”“疑似广告（未选）”“小图/图标（未选）”“不确定（未选）”“尚未加载”“无法读取”。标签是辅助判断，不给未经校准的 99% 等精度数字。

## 入口二：单图快捷翻译

支持悬浮按钮、右键菜单和默认 Ctrl+Shift+左键。只有用户启用站点后才能监听；组合键冲突时允许重新配置。鼠标指向图片外区域不触发任务。

首次使用显示简短上传说明与默认模式/单图预算，用户明确开启后，可在这个已披露设置和预算内一键提交；更换处理方或超过预算时再次提示。普通点击、文字输入和网页自身快捷键不被无差别拦截。

按下后图片边缘短暂高亮并出现真实阶段状态；动画不能覆盖全页、挡住正文，也不能以持续闪烁诱导用户等待。设置减少动态效果时用静态状态标签。

## 原位阅读与状态

| 状态 | 文案示例 | 可操作 |
|---|---|---|
| queued | 已排队 | 取消 |
| detect/ocr | 正在识别文字 | 请求取消、继续看其他图 |
| translate | 正在翻译 | 请求取消 |
| erase/inpaint | 正在清除原文 | 请求取消 |
| typeset/verify | 正在排版 | 请求取消 |
| succeeded | 翻译完成 | 原图、编辑、导出 |
| warnings | 已完成，部分区域需检查 | 定位问题、查看原图、修正 |
| failed | 未能完成，额度已释放/正在释放 | 查看原因、重试 |
| cancellation pending | 正在取消 | 不重复提交取消，不假装已退额 |
| offline | 网络已断开，任务可能仍在处理 | 恢复后重连查询 |

费用释放文案必须依据账本实际状态显示；不是所有错误发生时余额都已经更新。出错保留原图，不能留下白板或遮住原内容。

原译切换按钮固定在图片边缘可访问区域，不改变图像原比例。鼠标/键盘对照与移动视口兼容，退出对照恢复原状态。切换原图不重新计费。

## 编辑与补译

编辑器默认显示选中区域的原文、译文与安全区。支持改译文、字号、横向/纵向位置和撤销；字符数与最小字号有提示。溢出显示具体区域，不只在全页角落报错。

框选漏字区域使用原图坐标，确认后单独识别/翻译；显示新增成本。可取消擦字区域并保留原画译注。修改同一段的字号/位置和已有译文本身，仅重新排版，不重新发起模型翻译。

编辑冲突时保留用户当前文本，提供加载最新/另存版本；不直接用服务端新版本覆盖输入。原资产过期时告知需要重新提供图像，不能展示无限转圈。

## 导出

提供单图 PNG/JPEG、有序 ZIP；默认用原图分辨率和当前结果版本。导出前列明成功、需检查和失败数量，用户可以选择是否包含带警告结果；失败图不混进“已翻译”目录。

文件名用批次序号与短标识，例如 `0001-result.png`，不把完整浏览 URL 或敏感标题写入文件名。ZIP 带简短清单，记录成功项/警告/失败，超长图分段命名连续。

用户取消系统下载、浏览器拦截下载、导出链接过期和文件生成失败分别处理。导出失效可重建有效结果的导出包，不再次收翻译费。

## 可访问性与容错

- 侧栏和编辑器可用键盘完成主要操作，Esc 关闭浮层并恢复焦点。
- 所有图标按钮有可访问名称；错误状态同时有文本，不仅依赖红/绿颜色。
- 符合减少动态效果设置；处理状态更新不会每秒抢焦点或反复朗读。
- 缩放浏览器和高 DPI 时内容不截断；长图片列表采用有界渲染，不一次绘制全部大图。
- 服务商错误转为可理解文案，并保留可复制的错误编号供排查。
- 清空缓存和删除云端内容是不同动作；界面说明各自范围和保留例外。
