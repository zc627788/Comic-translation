# 验收、质量与证据

文档编号：D08；版本：0.1；上游：[D07 用户体验](ux.md)。

## 上一份完整总结

D07 把需求落为侧栏扫描、单图快捷入口、原位状态、对照、编辑、导出和账户流程，并列出权限、上传告知、预算变化、取消、离线、过期和部分成功行为。主流程不能显示假的进度、提前声称退额或覆盖错误图片。界面尚未实现，上游放行验收设计，不表示体验已经可用。

## 验收层级

1. 文档检查：链接、编号、任务覆盖、状态和前后矛盾。只能证明规格完整性。
2. 确定性测试：坐标、ID 映射、幂等、账本、状态机、安全边界和排版约束。
3. 集成验证：真实数据库、任务队列、对象存储、认证及服务适配器。
4. 扩展端到端：实际加载插件测试权限、跨域、休眠、快捷键、覆盖及下载。普通页面 mock 不能替代。
5. 模型和人工评估：真实 OCR/翻译/修复模型在固定授权集上运行，输出指标、抽样审阅和成本。
6. 发布/运维演练：全新环境构建、安装、服务恢复、迁移回滚及账本对账。

## 固定质量集与标注

目标 240 张，分为 6 组各 40 张：普通黑白气泡、振假名/小字、低清/压缩、黑底或网点、画面外文字/艺术字、长图/复杂排版。每张归属一个主组，同时附加标签，避免重复计入总数。

其中 160 张用于开发，80 张封存留出；按作品/来源分组切分，尽量避免同作品泄漏。标注正文区、应清除注音、保护背景、原文、阅读顺序及译文评估说明。无法辨认的源字明确标记，单独报告，不悄悄删除困难样本。

每次报告附数据集清单哈希、模型/代码/字体版本、参数、硬件、冷/热启动、网络条件、失败和降级数量。样本权利不允许公开时只提交匿名 ID、指标和可复现协议；本地私有证据不能谎称公开 CI 已运行。

## 初始质量门槛（目标，不是实测结果）

| 指标 | 定义 | P04 目标 |
|---|---|---|
| 正文区域召回 | 正确关联且覆盖标注文字面积 >=90% 的区域 / 所有应处理正文区域 | 总体 >=95%，各主组 >=90% |
| 振假名擦除覆盖 | 需要清除的注音像素中被正确掩膜包含的比例 | >=95%，同时报告背景误擦 |
| OCR 字符错误率 | 固定归一化后的编辑距离 / 标注字符数，正文与注音规则固定 | 可辨认正文总体 <=8%；困难组单报 |
| 无人工修改可读页 | 评审认为正文基本完整、无主要语义错误、字号可读的页数 / 所有测试页 | >=85%，失败页计入分母 |
| 严重画面损坏 | 误擦人物/关键线条、明显大块覆盖等页面 / 全部页面 | <=2%，每例需复查 |
| 排版溢出 | 译文像素超出允许区域的正文区域 / 全部正文区域 | <=1%；检测到溢出必须标记 |
| 重要译义正确 | 两位具日中理解能力评审按固定量表判断通过的对白 / 抽样对白 | >=90%，分歧复核；无评审不能宣称通过 |
| 艺术字策略透明 | 应降级艺术字有明确保留/译注和可关闭入口 | 100% 的已标记降级项 |

这些目标可在 P01 发现明显不可达时通过决策记录调整：保留原目标、实测依据、用户影响和新版本。不能到 P04 才静默降低指标，并继续宣传原目标。少量好样图不构成通过。

## 性能、资源和成本

- 标准测试输入：约 2MP 静态图片、每图 5～20 个正文区，指定默认模式，端到端计入上传与下载。
- 本地点击到状态反馈 P95 <=300ms；热服务在约定硬件/网络上单用户中位数 <=8s、P95 <=20s。至少 100 次记录，冷启动单列，不能混入缓存结果美化。
- 5 个并发用户各 20 个任务的可支持输入成功率 >=98%；排队时间、服务时间、429 和失败分别报告。不要求 CPU 回退与 GPU 同一速度。
- 30 分钟滚动/换图/恢复试验无持续增长的 DOM 覆盖层、监听器或失控内存；资源回收有测量。
- 上传、像素、标准页、超时、重试和成本上限按契约执行；无法在资源限制内完成时安全失败并释放额度。
- 成本记录来自实际运行和服务商账单/计价依据；按轻度、典型和重度月用量测算贡献毛利。正式套餐应覆盖变动成本并有明确安全余量，初始经营目标为典型用量贡献毛利 >=60%，不是保证盈利。
- 固定空闲资源、支付费、退款、客服和获客另报；若候选价格不能覆盖高消耗用户，必须调整额度/价格，不能用“将来缓存会省钱”直接放行。

## 缺陷分级和证据

- S0：泄密、跨用户泄露、严重账务损坏，立即停止受影响路径。
- S1：核心路径不可用、覆盖错误图、重复收费、普遍误擦，阻塞相关阶段和发布。
- S2：有明确绕行的局部问题，可登记后续任务，但不突破阶段验收门槛。
- S3：非阻塞文案/样式优化，列明后续安排。

报告写实际执行命令、环境版本、退出码、关键输出、测试集和失败列表。截图/录像不能包含用户隐私或付费凭据；报告中真实模型结果与 mock 测试分栏。每个阶段都使用 [总结模板](../../docs/templates/stage-summary.md)。
